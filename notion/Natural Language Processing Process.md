# Natural Language Processing Process



현재는 GPT 기반의 모델이 주로 자연어 생성에 많이 활용이 되고 있습니다. 뿐만 아니라 2020년대 이후로는 단순히 텍스트 데이터만을 사용하는 것이 아닌 이미지, 음성, 영상 등 여러 모달리티를 결합해 이해하거나 생성하는 멀티모달 모델과 단순 모델 예측으로 끝나지 않고 도구 사용을 판단하고 활용하는 에이전트가 활발히 연구되고 있는 추세입니다.

어텐션(Attention) 기법의 도입

어텐션(Attention) 기법이란?  

신경망이 입력 시퀀스의 모든 위치 중 특정 시점에 중요한 부분에 집중(가중치 할당) 하여 정보를 더 효율적으로 처리하도록 돕는 메커니즘입니다. 

2014년 Bahdanau(Additive) 어텐션이 처음으로 소개된 이후, Luong(Dot-product) 어텐션, Self-Attention, Scaled Dot-product, Multi-Head 어텐션 등 여러 종류와 변형이 등장하게 됩니다.

자연어 처리에 Attention 기법 도입


2014년 Bahdanau et al. Neural Machine Translation by Jointly Learning to Align and Translate 논뮨에서 처음으로 자연어 처리에 있어 Attention 기법을 도입하게 됩니다.

RNN/LSTM 구조는 시퀀스를 순차적으로 처리하면서도, 장기 의존성(Long-term Dependencies)을 완벽히 해결하지 못해 원문 문장의 특정 구간이나 중요한 단어 정보를 놓칠 위험이 있었습니다.

하지만 여기에 Attention 기법을 도입한다면, 입력된 단어에서 중요한 단어에 집중(가중치 부여)하여 정보 손실을 줄이고, 모델이 효과적으로 문맥을 이해할 수 있다는 이점을 얻어 기존 문제를 해결 할 수 있습니다.

트랜스포머(transformer) 모델의 등장

기계 번역을 위한 Seq2seq

임베딩과 RNN을 조합한 신경망 모델로 부터 기계번역 문제를 해결하고자 인코더와 디코더 구조를 가지는 Seq2seq 모델이 등장 합니다.



구조적 특징

인코더(Encoder) → 디코더(Decoder)로 구성되어, 인코더가 입력 시퀀스를 벡터로 요약하고, 디코더가 이를 바탕으로 출력 시퀀스를 생성함.

인코더(Encoder)

디코더(Decoder)

인코더와 디코더는 LSTM, GRU 등 순환신경망을 인코더와 디코더에 적용한 모델이 대표적

인코더 출력 전체를 바탕으로, 디코더가 각 시점에서 가장 관련성 높은 인코더 상태를 참조하기 위해 Attention 기법을 추가 하여 인코더의 정보 벡터를 생성

디코더를 활용하여 텍스트를 생성한다는 것에 있어서 텍스트 생성 모델의 초기 형태이기도 함

교사 강요 (Teacher Forcing) 학습

디코더의 타겟 시퀀스는 입력 시퀀스를 그대로 한 칸씩 밀어 구성, 현재 시점까지의 토큰으로 다음 순서의 토큰을 예측하게 학습

실제 학습할 때는, 이전 시점의 디코더 출력값이 틀렸더라도 다음 시점에 실제 정답(Ground Truth) 단어를 강제로 입력

이를 교사 강요(Teacher Forcing)라고 하며, 모델이 초기에 엉뚱한 예측을 하더라도 학습이 엇나가지 않고 빠르게 수렴할 수 있도록 도와줌

자기 회귀 (Autoregressive) 추론

실제 서비스 환경에서는 정답을 모르기 때문에, 이전 시점에 디코더가 예측한 출력 단어를 다음 시점의 입력으로 그대로 다시 사용

앞에서 한 번 예측이 틀리면 뒤로 갈수록 스노우볼이 굴러 문장 전체가 망가질 수 있는 구조적 취약성을 가짐

현재 최신 모델까지도 해당 방식을 통해 언어 생성

한계점

여전히 RNN의 순차 처리 문제, 긴 시퀀스 처리 시 성능 저하 문제 등으로 완벽에 가까운 번역에는 한계가 존재

순환 구조가 아닌 완전한 병렬화 처리가 가능한 어텐션 메커니즘(Self-Attention)에 초점이 맞춰지기 시작



Self-Attention만을 활용하는 transformer

RNN구조로 이루어져 있는 Seq2seq의 문제를 해결하기 위해 Self-Attention 만으로 층을 이루는 아키텍처를 개발 하게 됩니다.  

Self-Attention: 입력 시퀀스의 각 위치(각 토큰)가 모든 위치(다른 토큰들)와 어텐션을 통해 상호작용함으로써, 시퀀스의 위치(각 토큰)별 연관성을 파악.

이러한 Self-Attention을 위주로 인코더와 디코더 구조를 만들고 학습을 하여 입력된 전체 토큰들의 상호작용, 즉 토큰간의 연관성에 대한 정보를 저장하는 아키텍처를 만들 수 있습니다.

이렇게 만들어진 모델 아키텍처인 Transformer는 다음과 같이 기존 RNN 구조의 문제점을 해결할 수 있게 됩니다.

완전한 병렬처리

RNN은 무조건 토큰을 순서대로 입력 받아야 하므로 병렬 연산 자체를 수행할 수 없음

Transformer는 모든 토큰 쌍에 대한 스코어 계산을 매트릭스 연산으로 병렬 처리하여 훨씬 빠른 연산이 가능 

가중치를 통해 중요 토큰만 선별적으로 강하게 반영하므로, 모델 파라미터가 늘어나도 시간 복잡도가 RNN 대비 크게 유리

포지셔널 인코딩 (Positional Encoding)

단어를 동시에 입력받다 보니, 모델 입장에서는 어떤 단어가 앞에 있고 뒤에 있는지 '어순(위치 정보)'을 알 수 없는 문제가 발생

단어 고유의 의미를 담은 임베딩 벡터에, 단어의 문장 내 절대적/상대적 위치 정보를 담은 수학적 함수 벡터를 더해줌

이를 통해 모델은 순차적으로 데이터를 받지 않고도 각 단어의 위치를 완벽하게 인지

RNN과의 비교

RNN 구조와 달리 멀리 떨어진 단어끼리도 직접적인 연결을 맺을 수 있어, 장기 의존성을 처리하기 쉽고 성능 향상에 크게 기여

병렬 연산을 통해 기존 RNN에 비해 훨씬 빠른 속도로 연산 처리 가능

기계 번역, 질의응답, 텍스트 요약 등 다양한 자연어 Task에서 기존 RNN 모델에 비해 훨씬 뛰어난 성능을 제공

BERT, GPT 등 사전 학습(Language Model) 프레임워크의 기반 모델로 발전해 대규모 학습 가능.
