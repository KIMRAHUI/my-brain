# NLP Intro

자연어 처리란?

인공어

자연어

컴퓨터는 인공어로만 소통하기 때문에 자연어를 다루려면 별도의 처리 과정이 필요

자연어 처리(NLP; Natural Language Processing)

자연어 데이터를 컴퓨터가 처리할 수 있는 형태로 변환하여 의미 있는 분석을 수행하는 과정

크게 자연어 이해(NLU; Natural Language Understanding)와 자연어 생성(NLG; Natural Language Generation)로 나눌 수 있음



다양한 자연어 처리 Task

텍스트 분류 (Text Classification)

텍스트를 특정 카테고리로 분류

예: 스팸 메일 필터링, 뉴스 기사 분류

감성 분석 (Sentiment Analysis)

텍스트에서 감정을 분석

예: 긍정/부정 리뷰 분석, 소셜 미디어 여론 파악

기계 번역 (Machine Translation)

자연어를 다른 언어로 변환

예: 영어 → 한국어 번역, 다국어 웹페이지 번역

문서 요약 (Text Summarization)

긴 문서에서 핵심 내용을 추출하거나 생성

예: 뉴스 기사 요약, 논문 요약

질의응답 (Question Answering, QA)

질문에 대한 답변 제공

예: 주어진 텍스트 데이터를 기반으로 질문에 답변, 질문에 대한 답변을 생성 

자연어 생성 (Natural Language Generation, NLG)

입력 데이터를 바탕으로 새로운 텍스트 생성

예: 자동 보고서 작성, 챗봇 대화 생성

음성 인식 및 변환

음성을 텍스트로 변환(stt)하거나 텍스트를 음성으로 변환(tts).

예: 음성 비서 서비스 (시리, 구글 어시스턴트), 오디오북 생성

정보 추출

개체명 인식(Named Entity Recognition, NER)

관계 추출 (Relation Extraction)

문장 유사도(Sentence Similarity)



자연어 처리의 주요 단계

데이터 수집 및 정제

웹, 데이터베이스, API 등을 통해서 텍스트 데이터를 확보하는 과정

확보한 데이터 중 불필요한 정보나 노이즈를 제거하여 분석에 적합한 상태로 정제

텍스트 전처리

불필요한 태그, 특수문자, 노이즈를 제거하거나 문서 의미 해석에 영향이 적은 불용어(Stopwords)를 걸러내는 클렌징 작업

언어 특성에 맞춘 형태소 분석 및 미등록어(OOV) 문제를 해결하는 서브워드 분절 기법(BPE 등)을 활용한 토큰화 작업

통계 기반의TF-IDF부터 문맥적·의미적 관계를 보존하는 밀집 벡터 표현(Word2Vec, Sentence Embedding 등)을 적용하여 컴퓨터가 연산 가능한 수치형 벡터화 

모델 학습 및 적용

수집된 텍스트를 벡터화한 뒤 머신러닝 또는 딥러닝 모델을 학습하는 과정

CNN, RNN, Transformer(BERT, GPT 등) 같은 다양한 딥러닝 아키텍처가 활용

사전 학습과 미세조정(파인튜닝)에 따라 텍스트 분류, 문서 요약, 질의응답, 챗봇 등 다양한 응용 모델로 발전 가능

평가(Evaluation) 및 개선

정확도(Accuracy), 정밀도(Precision), 재현율(Recall), F1 스코어 등 여러 지표를 통해 모델 성능을 평가

언어 생성 모델의 경우 BLEU, ROUGE, METEOR 등 자연어 생성 품질을 평가하는 지표를 활용

애플리케이션 구축 및 배포 (RAG & Agent)

학습·검증된 언어 모델을 단독 추론에 그치지 않고 실제 사용자 서비스 환경으로 확장하는 과정

벡터 DB 기반의 검색 증강 생성(RAG)을 연계하여 모델의 환각(Hallucination)을 줄이고 최신 도메인 지식 검색 서비스 구현

API 호출 및 코드 실행 등 외부 도구와 다단계 추론을 결합한 AI 에이전트를 구축하여 복잡한 업무 자동화 워크플로우를 완성

왜 자연어 처리(NLP)를 배워야 하는가?

비정형 데이터의 중심 활용

기업과 인터넷 세상에 존재하는 데이터의 약 80% 이상은 문서, 메신저 대화, 리뷰, 로그 등 텍스트 기반의 비정형 데이터

NLP는 단순 수치 데이터 분석을 넘어 이러한 방대한 비정형 자산에서 비즈니스 인사이트를 도출하는 핵심 도구

인터페이스 패러다임의 변화 (UI/UX 혁신)

GUI(버튼, 메뉴 클릭) 중심의 인터페이스 → 자연어로 컴퓨터와 대화하고 명령을 내리는 CUI(Conversational UI) → AI가 직접 소프트웨어 작업을 수행하는 AI 에이전트

최신 생성형 AI 생태계의 기초 기반

ChatGPT, Claude 등 최신 거대 언어 모델(LLM)과 멀티모달 AI의 근간은 Transformer 기반 자연어 처리 기술

NLP의 원리를 이해해야 프롬프트 엔지니어링 수준을 넘어 LLM을 효과적으로 튜닝하고 제어할 수 있음

접근 가능한 직무 및 진로

AI / NLP 엔지니어 (Natural Language Processing Engineer)

텍스트 분류, 감성 분석, 정보 추출 등 도메인 특화 언어 모델을 설계하고 실제 서비스 환경에 맞게 학습·최적화

LLM 애플리케이션 엔지니어 (LLM Application Developer)

LangChain, LangGraph 등의 프레임워크와 RAG 기술을 결합하여 사내 지식 검색 시스템, 맞춤형 챗봇, AI 기반 업무 자동화 솔루션을 구축

AI 에이전트 아키텍트 (AI Agent System Engineer)

외부 API, 데이터베이스, 검색 도구와 LLM을 결합하여 복잡한 다단계 의사결정을 자율적으로 수행하는 에이전트 파이프라인을 설계하고 배포

AI 솔루션 연구원 및 MLOps 엔지니어

오픈소스 모델(Llama, Mistral 등)을 경량화 기법(PEFT, 양자화)을 적용해 자체 인프라 또는 온디바이스/에지 환경에 효율적으로 서빙하고 모니터링

비정형 데이터 분석가 (Text Data Analyst)

고객 VoC, 소셜 미디어 여론, 뉴스 데이터 등 대규모 텍스트로부터 키워드 트렌드, 토픽 모델링, 고객 이탈 시그널을 발굴하여 비즈니스 의사결정을 지원
